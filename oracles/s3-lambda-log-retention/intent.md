The bucket is configured to invoke that function on s3:ObjectCreated:Put (an object-upload event) — the notification configuration's Lambda target must reference the function this scenario creates, and a resource-based Lambda permission must grant s3.amazonaws.com the right to invoke it, scoped to this specific bucket (no wildcard, no unrelated/hardcoded ARN).
